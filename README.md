# BeatBox
This is a Java application for generating drum sound. This application can connect to a [BeatBoxServer](https://github.com/CesarMoromisato/BeatBoxServer), which multiple instances of BeatBox app can connect to, creating a "multiplayer game", where you can share your drum patterns and send messages.

![Beat box interface](https://github.com/user-attachments/assets/6fe2d91a-cf48-49eb-aafb-ec07297c450e)

# Motivation
First of all, learn Java. Also, explore different APIs such as Swing GUI, the MIDI interface, and basic connection methods. In this project, we used the basics of multithreading and serialization to save the drum patterns to a file.
